# Changelog

## Version 1.0.0 (2026-10-03)

- Initial version
- Support for custom key in password store with `PASS_FASTMAIL_MASKED_KEY`
- Arguments:
  - `--clip,-c`: to clip the masked email to the clipboard
  - `--domain,-d`: to set the masked email's domain
  - `--force,-f`: to force replacing existing entry
  - `--version,-v`: show version number
